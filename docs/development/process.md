# Norm Development Process

## Language development phases

1. Specification
2. Prototype interpreter
3. Type checker
4. Truffle backend
5. Standard library
6. Native backend

## Compiler driven development

Every language feature must include:

- syntax definition
- semantic rules
- compiler implementation
- runtime support
- tests

## AI assisted development

AI can assist migration and code generation, but all generated code must pass the Norm compiler.
