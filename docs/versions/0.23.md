# Norm 0.23

Norm 0.23 提供编译后 Core 模块发布、增量重链接、作用域任务、块调用链与结果构建器，并支持 Java 注解处理器读取应用模板资源。

## 模块与运行

NAR 包携带编译后 Core，消费端复用发布模块并按当前依赖重链接。编译缓存、应用准备缓存和 Windows 启动器均以内容身份区分输入。包格式升级到 7，旧格式包需要由本版本重新打包并发布新包版本；格式边界见[包管理器](/ecosystem/package-manager)。

## 语言与工具

块调用链、结果构建器、类型化上下文、作用域任务、资源所有权和字段观察提供统一的语言与运行时接口。标准库声明中的 `@Document` 是接口说明的唯一来源，入口见[标准库 API](/stdlib/api)。编辑器语义分析和命令行复用同一编译器边界。

## HTML 与 Java 适配

应用资源在 Java 注解处理前进入编译输出，支持 JStachio 的文件模板和内联模板。Micronaut HTML 集成通过独立适配包提供；编译器不内置框架专用逻辑。显式 Java 模块按声明的根模块和必需依赖加载。契约及验证入口见[Java 适配](/design/java-library-adapters)。

## 安装与迁移

CLI 和 VS Code 扩展应升级到同一版本，已有模块包必须匹配当前 Core 与 NAR 格式。各平台交付和安装方式见[发布流程](/design/release-process)。发布物尚未进行平台代码签名，系统可能显示来源警告。
