# Norm 0.24

Norm 0.24 提供 Java class 继承投影、稳定的宿主回调身份和外部事件完成任务源。

## Java 互操作

公开父类关系保留在生成声明中，泛型参数跨包私有中间父类传递。相同 Java 对象经过不同名义视图时保持 identity 和哈希一致；相同 Norm 函数重复投影为同一 SAM 类型时保持监听器身份。Comparator 适配与验证入口见 [Java 适配](/design/java-library-adapters)。

## 并发

`std.concurrent.Completion<T>` 把外部事件接入标准 Task。接口与测试索引见[并发 API](/stdlib/concurrency)。

## 安装与迁移

Java 绑定 ABI 为 `norm-java-binding-2`。旧绑定包必须重新打包并发布新整数版本；包含标准库 Core 契约的依赖也需匹配当前工具链。CLI 与 VS Code 扩展应同时升级。发布和安装方式见[发布流程](/design/release-process)。发布物尚未进行平台代码签名，系统可能显示来源警告。
