# Norm 0.9

Norm 0.9 完成 class 构造与单继承的纵向语言实现。

## 语言

- class 支持一个显式构造器和按路径验证的字段确定初始化；
- 子 class 显式调用父构造器，并继承 public 字段与方法；
- public 方法按签名覆盖，在 class、泛型父类型和 interface 视图中动态分派；
- private 方法不参与继承和覆盖。

## 工具链

- SemanticModel 保存父类型投影与覆盖关系；
- Bound、Core 和 Truffle 共用构造入口、全继承链字段布局和方法分发表；
- Core 身份边界升级为 Schema V5 与 Language Semantics V5；
- parser、formatter、Language Server 与运行时共享同一继承模型。

完整规则见 [Class 声明](/spec/grammar/classes)。
