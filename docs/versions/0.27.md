# Norm 0.27

Norm 0.27 establishes the current Core ABI baseline for the package ecosystem. Published packages must be rebuilt with this toolchain; packages from earlier Core ABI generations are not accepted by the resolver.

The documentation exporter can generate structured API documentation and a repository-owned `SKILL.md` from the same semantic model. Package repositories use the [package template](https://github.com/normlanguage/package-template) and publish code, API documentation and Skill content from the same release tag.

The package migration contract is indexed in [Skill publication](/ecosystem/skill-publication) and the [release process](/design/release-process).
