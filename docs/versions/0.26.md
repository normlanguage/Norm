# Norm 0.26

Norm 0.26 supports self-contained GitHub module delivery for desktop components. Java-backed NARs include their pinned runtime dependency graphs; consumers verify the embedded content before linking. The packaging and loading contract is indexed in [Java library adapters](/design/java-library-adapters).

Completed asynchronous tasks remain accessible while a guest handle is live. Resource ownership and handle reachability are verified by `ResourceScopeTest` and `TaskExecutionTest` in the compiler test suite.

JDK binding declarations use `jdkModule` for platform types. [Java adapters](/design/java-library-adapters) defines type ownership, package identity and runtime requirements. Desktop libraries remain in the official [ui](https://github.com/normlanguage/ui), [ui-fx](https://github.com/normlanguage/ui-fx), [ui-component](https://github.com/normlanguage/ui-component) and [theme](https://github.com/normlanguage/theme) repositories.

Use a matching Norm toolchain to consume packages produced with this compiler contract. Native application builds and platform acceptance follow [Application builds](/tooling/application-build) and the [release process](/design/release-process).
