# Norm 0.25 candidate

Norm 0.25 is an implementation candidate, not a published release. The public 0.24 assets do not include the capabilities described here.

## Applications and examples

`norm hello` creates five independent, single-file programs: a first program, bubble sort, a maze solver, a desktop Todo, and a local message board. The [generated guide](../../cli/compiler/src/main/resources/hello/README.md) gives JVM run and native build commands. The board depends on unpublished candidate libraries and requires locally prepared compatible packages.

`norm build` targets GraalVM Native Image by default. A built application runs without Norm or Java on the target machine; the build machine still needs a platform C toolchain. See [Application Builds](/tooling/application-build) for output names, toolchain preparation, and delivery boundaries.

## Language, agents, and libraries

The [learning path](/learn/) now advances through independently executable feature lessons. The [language examples](../../norm/tests/docs/language) serve the reference, while [library samples](/stdlib/samples) remain in their owning repositories.

`@Document` descriptions flow through semantic queries, hover, completion, and API export. Agent workflows can query declarations, inspect references and tests, preview a rename, and validate the result. See [Agent Development](/tooling/agent) and [API Documentation Export](/tooling/api-documentation).

Java interoperability preserves object identity in returned collections and projects nested generic relations consistently. See [Java adapters](/design/java-library-adapters) for the shared binding contract.

## Migration boundary

Use CLI, editor, and NAR packages built against the same 0.25 toolchain and Core contracts. Java binding packages introduced under `norm-java-binding-2` require compatible integer package versions; an older public asset is not a substitute for a rebuilt candidate dependency. Adapter samples that require unpublished packages explain their local preparation in the [library sample setup](/tooling/library-samples). The [release process](/design/release-process) defines publication and platform acceptance.
