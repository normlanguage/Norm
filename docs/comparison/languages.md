# Norm Compared With Existing Languages

## Norm vs Java

保留：

- 类型前置
- class
- interface
- exception
- annotation

改进：

- 非空默认
- 顶层函数
- value semantics
- reified generics

## Norm vs Kotlin

Norm 不采用大量语言关键字扩展。

拒绝：

- lateinit
- extension magic
- 过多语法糖

## Norm vs Rust

借鉴：

- Result
- enum
- 显式资源模型

不采用：

- ownership
- borrow checker

## Norm vs Go

目标：

保持 Go 的部署简单性，同时提供更强类型模型。
