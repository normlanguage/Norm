# Norm Ecosystem Strategy

## 第一阶段

借助 Java 生态快速建立可用性。

```
Norm API
 ↓
Adapter
 ↓
Java Library
```

重点组件：

- JDBC
- HTTP
- JSON
- Time
- Crypto

## 第二阶段

逐步替换为 Norm Native 实现。

```
Norm API
 ↓
Norm Runtime
 ↓
Native Implementation
```

## AI Migration

通过 Java -> Norm 规则体系迁移成熟代码。

流程：

Java Source
 ↓
AI Migration
 ↓
Norm Code
 ↓
Norm Compiler Verification
