# Norm 0.25 候选版

Norm 0.25 目前是实现候选，尚未正式发布。公开的 0.24 资产不包含本页所述能力。

## 应用与示例

`norm hello` 生成五个相互独立的单文件程序：入门程序、冒泡排序、迷宫求解、桌面 Todo 与本地留言板。[生成的指南](../../../cli/compiler/src/main/resources/hello/README.zh-CN.md)列出 JVM 运行和原生构建命令。留言板依赖尚未发布的候选库，须在本地准备兼容的软件包。

`norm build` 默认使用 GraalVM Native Image。生成的应用在目标机器上运行时无需 Norm 或 Java；构建机器仍需相应平台的 C 工具链。产物名称、工具链准备与交付边界见[应用构建](/zh/tooling/application-build)。

## 语言、Agent 与库

[教学路径](/zh/learn/)现按特性提供可独立执行的小节。[语言示例](../../../norm/tests/docs/language)供参考文档引用，[库示例](/zh/stdlib/samples)则由各自的库仓库维护。

`@Document` 说明进入语义查询、悬停提示、补全和 API 导出。Agent 可以查询声明、检查引用和测试、预览重命名并验证结果。入口见 [Agent 开发](/zh/tooling/agent)和 [API 文档导出](/zh/tooling/api-documentation)。

Java 互操作保持返回集合中的对象身份，并一致地投影嵌套泛型关系。共享绑定契约见 [Java 适配](/zh/design/java-library-adapters)。

## 迁移边界

CLI、编辑器和 NAR 包须与同一套 0.25 工具链和 Core 契约匹配。`norm-java-binding-2` 下的 Java 绑定包需要兼容的整数包版本；较早的公开资产不能替代重新构建的候选依赖。需要未发布软件包的适配库示例，在[库示例准备指南](/zh/tooling/library-samples)说明本地准备方式。发布与平台验收规则见[发布流程](/zh/design/release-process)。
