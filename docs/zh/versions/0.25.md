# Norm 0.25

Norm 0.25 将下面的语言示例、Agent 工具、应用构建和 Java 互操作能力纳入同一正式版本。

## 应用与示例

`norm hello` 生成五个相互独立的单文件程序：入门程序、冒泡排序、迷宫求解、桌面 Todo 与本地留言板。[生成的指南](../../../cli/compiler/src/main/resources/hello/README.zh-CN.md)列出 JVM 运行和原生构建命令。Todo 当前的自动化验收覆盖 Windows x64；Linux 和 macOS 的图形运行尚未验证。留言板的 `Module module()` 声明列出所需库依赖。

`norm build` 默认使用 GraalVM Native Image。生成的应用在目标机器上运行时无需 Norm 或 Java；构建机器仍需相应平台的 C 工具链。产物名称、工具链准备与交付边界见[应用构建](/zh/tooling/application-build)。

## 语言、Agent 与库

[教学路径](/zh/learn/)现按特性提供可独立执行的小节。[语言示例](../../../norm/tests/docs/language)供参考文档引用，[库示例](/zh/stdlib/samples)则由各自的库仓库维护。

`@Document` 说明进入语义查询、悬停提示、补全和 API 导出。Agent 可以查询声明、检查引用和测试、预览重命名并验证结果。入口见 [Agent 开发](/zh/tooling/agent)和 [API 文档导出](/zh/tooling/api-documentation)。

Java 互操作保持返回集合中的对象身份，并一致地投影嵌套泛型关系。继承的 Java 方法在多层泛型祖先链上保留代入后的类型实参，并分派到声明该方法的宿主入口。共享绑定契约见 [Java 适配](/zh/design/java-library-adapters)。

## 迁移边界

CLI、编辑器和 NAR 包须符合兼容的编译器与 Core 契约。每个库的 `module.norm` 声明软件包坐标和依赖版本；未变化的公开 NAR 经 0.25 消费者验收后可继续复用，发生变化的模块发布新的整数版本，不覆盖现有 Release。软件包准备见[库示例指南](/zh/tooling/library-samples)，平台验收边界见[发布流程](/zh/design/release-process)。
