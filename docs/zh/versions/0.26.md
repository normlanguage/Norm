# Norm 0.26

Norm 0.26 支持通过 GitHub 交付自包含桌面组件模块。带 Java 绑定的 NAR 包含固定的运行依赖图，消费时校验内嵌内容再链接。封装与加载契约见 [Java 库适配](/zh/design/java-library-adapters)。

异步任务完成后，仍存活的语言句柄可继续访问任务。资源所有权与句柄可达性由编译器测试集中的 `ResourceScopeTest` 和 `TaskExecutionTest` 验证。

JDK 平台类型通过 `jdkModule` 声明绑定。类型归属、包身份及运行要求以 [Java 适配](/zh/design/java-library-adapters) 为准。桌面库分别维护于正式的 [ui](https://github.com/normlanguage/ui)、[ui-fx](https://github.com/normlanguage/ui-fx)、[ui-component](https://github.com/normlanguage/ui-component) 与 [theme](https://github.com/normlanguage/theme) 仓库。

使用匹配的 Norm 工具链消费当前编译契约生成的包。原生应用构建与平台验收见 [应用构建](/zh/tooling/application-build) 和 [发布流程](/zh/design/release-process)。
