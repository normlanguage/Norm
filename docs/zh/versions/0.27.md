# Norm 0.27

Norm 0.27 建立包生态使用的当前 Core ABI 基线。所有已发布包都必须使用这套工具链重新构建，旧 Core ABI 的包不会被解析器继续接受。

文档导出器可以从同一份语义模型生成结构化 API 文档和仓库内的 `SKILL.md`。包仓库统一使用 [包模板](https://github.com/normlanguage/package-template)，代码、API 文档和 Skill 必须来自同一个发布标签。

包迁移契约见 [Skill 发布](/zh/ecosystem/skill-publication) 和 [发布流程](/zh/design/release-process)。
