# 容器部署

Norm Web 应用可以构建为原生可执行文件或带运行时的应用包。容器镜像只包含运行所需文件，并以非 root 用户启动。

## 镜像原则

- 使用多阶段构建隔离编译工具链；
- 固定基础镜像 digest，生成 SBOM 和校验信息；
- 不把源码仓库、测试凭据或本地缓存复制进运行镜像；
- 配置和秘密在运行时注入，不烘焙进镜像层；
- 文件系统默认只读，临时数据写入明确挂载点。

## 进程模型

应用作为容器 PID 1 时必须处理终止信号：停止接收新请求、等待有限时间完成在途工作、flush 可观测数据，然后退出。强制超时后返回非零状态。

## 健康检查

`/live` 只表示进程仍可工作；`/ready` 表示可以接收流量。ready 可以考虑关键初始化状态，但不应因一个可降级的下游短暂故障反复重启容器。

## 资源

运行时读取 CPU 与内存限制来设置线程、堆和连接池默认值。超出资源限制的行为必须通过指标可见，不能假设宿主机总资源都可用。

镜像 tag 用于人类识别，部署清单应固定不可变 digest。
