# References

Learn [type declaration references](/learn/type-references), [field declaration references](/learn/field-references), and [function declaration references](/learn/function-references) before using [lexical `ref<T>`](/learn/lexical-references) and [field handles](/learn/field-handles). The [declaration reference](/spec/declaration-references) and [`ref<T>`](/spec/grammar/references) specifications define their different lifetimes.
